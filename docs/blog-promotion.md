틈틈잇은 **하루 5분, AI가 정리한 요약을 읽고 퀴즈로 복습하는 학습 앱**입니다. 공부를 "시간 내서 하는 일"이 아니라 "틈에 하는 일"로 바꾸고 싶었습니다.

## 왜 만들었나요?

공부가 안 되는 건 의지보다 **시작이 너무 무겁기 때문**이라고 생각했습니다. 하루 1~2시간의 부담, 하루만 빠져도 끊기는 흐름. 그래서 기준을 바꿨습니다. **"하루 5분이면 충분하다. 대신 매일 이어가자."**

## 이렇게 사용해요

1. 카카오·구글 로그인 후 학습량, 주제, 난이도, 기간, 알림 시간 선택
2. 알림이 오면 홈의 간식 캐릭터를 눌러 시작
3. AI 요약 읽기 → OX·객관식 퀴즈 → 즉시 채점·해설
4. 스탬프 적립, 캐릭터 변화

## 주요 기능

- **내 PDF로 공부하기**: 강의 자료·논문(최대 50MB)을 오늘 분량으로 정리
- **실시간 AI 요약**: 생성되는 글이 바로 흘러나와 대기 없이 읽기 시작
- **출퇴근 시간 맞춤 알림**
- **스탬프 캘린더 · 연속 학습일 · 라이브러리 · 리그**
- 분량을 마친 뒤 보상형 광고로 1회 추가 학습 (앱은 무료)

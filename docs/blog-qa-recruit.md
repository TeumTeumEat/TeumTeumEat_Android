## QA 설명

**[테스트 범위]**

가입부터 **오늘의 요약 읽기 → 퀴즈 풀이 → 결과 확인**까지, 하루 학습 한 사이클을 끝까지 마치는 흐름을 확인합니다.

봐 주실 지점은 네 가지입니다.
· 온보딩(학습량·주제·난이도·기간·알림 시간 설정)이 헷갈리거나 길게 느껴지는 곳이 없는지
· AI 요약의 분량과 난이도가 5분 안에 읽기에 적당한지
· 퀴즈 문제와 해설이 학습에 도움이 되는지, 어색한 문제는 없는지
· 홈 화면의 간식 캐릭터, 스탬프 캘린더가 "내일도 해야겠다"는 마음이 들게 하는지

리그, 보상형 광고로 받는 추가 학습은 테스트하지 않아도 됩니다.

**[권장 환경]**

· Android 8.0(API 26) 이상 스마트폰
· 처음 가입하는 계정(카카오 또는 구글)으로 진행해 주세요.
· 학습 주제는 관심 있는 카테고리 아무거나 고르시면 됩니다. 하루 학습량은 **3문제**를 권장합니다.

**[진행 순서]**

1. 테스트 URL로 이동해 앱을 설치하고 실행합니다.
2. 카카오 또는 구글로 로그인합니다.
3. 온보딩에서 하루 학습량, 학습 주제, 난이도, 학습 기간, 알림 시간을 선택합니다. 알림 권한은 허용해 주세요.
4. 홈 화면의 간식 캐릭터를 눌러 오늘의 학습을 시작합니다.
5. AI가 생성하는 요약을 끝까지 읽습니다.
6. OX·객관식 퀴즈를 풀고, 문항마다 나오는 정답과 해설을 확인합니다.
7. 결과 화면에서 정답 개수와 문항별 해설을 확인합니다.
8. 라이브러리에서 방금 한 학습 기록과 스탬프를 확인합니다.
9. (선택) 마이페이지에서 알림 시간을 현재 시각 직후로 바꿔, 알림이 도착하는지 확인합니다.
10. (선택) 내 PDF를 올려 학습 목표를 하나 더 만들어 봅니다. 이때 진행 중이던 목표가 새 목표로 바뀝니다.

퀴즈 정답률을 평가하는 테스트가 아닙니다. 요약이 읽기에 부담 없었는지, 퀴즈가 요약 내용과 잘 이어졌는지, 앱이 막힘 없이 동작했는지를 봐 주세요.

**[피드백 요청]**

오류나 화면 깨짐, 느린 구간을 발견하셨다면 **기기 모델과 Android 버전**을 주관식 답변에 함께 남겨 주세요. 스크린샷이 있으면 더 좋습니다.

테스트를 완료하고 마지막 주관식 질문에 **앱 안 닉네임**을 남겨 주시면 확인 후 ★ 감사 보상을 추가로 드립니다. (보상을 운영하지 않는다면 이 문단은 삭제하세요)
